# Reglas del proyecto

- Lee la memoria completa, el README de la carpeta afectada y las reglas aplicables antes de trabajar. Mantén esta memoria sincronizada con decisiones y estado verificables; enlaza las fuentes detalladas en lugar de duplicarlas innecesariamente.
- Mantén los cambios dentro del alcance solicitado y conserva cambios preexistentes. No inventes contratos, integraciones, métricas ni datos de usuarios.
- Protege secretos y datos personales: no incluyas credenciales, CV ni información real de candidatos en código, ejemplos, pruebas o registros.
- Comprueba el comportamiento afectado con la validación disponible más específica. Declara explícitamente cualquier comprobación omitida y su motivo.
- Antes de un commit aplica `.agents/skills/delivery-check/SKILL.md`; no hagas commit, push ni abras un PR sin autorización.
- Para el tracker, conserva su contrato de API, su interfaz en español y las restricciones de `uis/talent-pipeline-tracker/DOMAIN.es.md`.
